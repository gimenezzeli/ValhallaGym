¿Cómo usar las rutinas?

Seguí estos simples pasos para encontrar el entrenamiento que mejor se adapte a tus objetivos.

1. Elegí tu objetivo

Seleccioná el tipo de entrenamiento que querés realizar: Fuerza, Hipertrofía, Calistenia o Circuitos de cardio.

2. Elegí tu nivel

Dentro de cada rutina vas a encontrar opciones para Principiante, Intermedio y Avanzado.

3. Descargá la rutina

Descargá el archivo y, si necesitás realizar modificaciones, consultá con un entrenador.
